# プロンプト実験ログ

試したこと・結果・理由を、その場で1行ずつ足していく場所。
**失敗こそ残す。**同じ失敗を二度やらないための台帳。

Discordで送るだけで追記される：

> **記録して** Veoで高デンシティ試した→成功。カット3つを1.5秒ずつ

種類を分けたいときは頭に付ける（省略すると実験ログに入る）：

- 「記録して …」        → このファイル
- 「知見メモ …」        → `youtube_insights.md`
- 「失敗メモ …」        → `failed_patterns.md`

読み返すときは Discordで「**実験ログ見せて**」。

書き方の型（迷ったらこれ）：
`何を試したか → どうなったか → なぜそうなったと思うか`
