# 想工業 会社紹介動画（60秒）ナレーション原稿・第1稿

いまのマスター（v5・59秒）は **BGMのみ・ナレーション無し**で作ってある。
ここに声を足すための原稿。2案とも、既存のテロップ5枚はそのまま残す前提。

## 書くときに置いた原則

1. **テロップが出ている間は、しゃべらない。**文字と声で同じことを言うと、
   どちらも頭に入らない。テロップは「読ませる」、ナレーションは「つなぐ」。
2. **既存テロップの文言を読み上げない。**重複は野暮になる。
3. **数字（#13の定着率）は読まない。**目で読ませたほうが強い。
   ここはBGMのドロップ（32秒）と重なる山場なので、音だけで持たせる。
4. **前半は求職者、後半は企業担当者。**44秒以降でB2Bの言葉に切り替える。
5. 速度は**1秒5.5文字**で計算（落ち着いた企業VPの標準）。枠に対して余白を残す。

## 音として仕上げるときの手順（原稿確定後）

1. **声を作る** — Higgsfield `generate_audio`（スピーチ専用。音楽には使えないが声は出る）。
   行ごとに別ファイルで出し、上表の秒数に置く。1本で通して読ませると尺が合わない。
2. **BGMを作り直す** — `bgm.py` の書き出しを、声が乗る区間だけ **−7dB** 沈める
   （キックのサイドチェインと同じ仕組みを、声をトリガーにして掛ける）。
   32秒のドロップと48–54秒のピークは、声が無いので**沈めない**。
3. **多重化** — 無音マスターに声とBGMを重ねる。
   ```
   ffmpeg -y -i renders/silent.mp4 -i mix.wav \
     -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest \
     -movflags +faststart renders/master_narration.mp4
   ```

## 確認が要ること

- **この原稿に、確かめていない事実は入れていない。**創業年・所在地・従業員数・
  加工精度などは、資料に無いので書いていない。入れたい場合は数字をもらってから。
  （第3稿で存在しない設備を2つ描いて作り直しになった件と同じ轍を踏まないため）
- B案の「朝、七時半。」だけは**始業時刻の仮置き**。使うなら要確認。
- ナレーション追加は**修正3回の枠の外**（納品済みのため）。追加費用の扱いを決めること。
